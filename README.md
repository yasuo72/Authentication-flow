# B2B SaaS Authentication Module Assignment

## Assignment Overview

This repository contains the completed assignment for designing an authentication module for a B2B SaaS product, including:

1. A technical flowchart description
2. User stories for key authentication features

## Directory Structure

- `/flowchart/` - Contains the authentication flowchart description
- `/user_stories/` - Contains detailed user stories for selected features

## Flowchart Details

The authentication flowchart (`flowchart/authentication_flowchart_description.md`) covers:

- Email/Password Login
- Social Sign-In (Google, LinkedIn)
- Single Sign-On (SSO)
- Multi-Factor Authentication (MFA)
- Account Creation
- Account/Password Recovery
- Optional steps like captcha and "remember device"

The flowchart uses the required elements:
- **Oval**: Start/End of a process
- **Parallelogram**: User input
- **Diamond**: Decision point (Yes/No)
- **Rectangle**: Backend/system process

## User Stories

Two features were selected for detailed user stories:

1. **Multi-Factor Authentication (MFA)**
   - User Story 1: Setting Up MFA (Administrator perspective)
   - User Story 2: Completing MFA During Login (End User perspective)

2. **Password Recovery**
   - User Story 1: Initiating Password Recovery (End User perspective)
   - User Story 2: Completing Password Reset (End User perspective)

Each user story includes:
- User Role(s)
- Objective/Description
- Acceptance Criteria
- Error States with error messages
- Open Questions
